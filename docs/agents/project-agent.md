# Agent — Project

**Rôle :** projets, planning, budget, scénarios, résultats.

- **Socle existant :** hub chantier (`chantier.js` : prospection BOAMP, dossier,
  phasage 4D, budget, équipe, simulation), `Project` du Core.
- **Entrées :** objectif (ex. « améliorer cette place publique »), contraintes,
  budget.
- **Sorties :** modèle du projet (géométrie, flux, contraintes, objectifs),
  scénarios chiffrés, planning, livrables.
- **Frontière :** ne décide pas à la place des élus/acteurs ; présente les
  conséquences de chaque choix.
- **Règles :** temporalité (4D) ; provenance des chiffres ; estimer ≠ garantir.

**Position :** Phase 1 (entité `Project`) + Phase 4 (scénarios).
