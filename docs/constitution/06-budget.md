# 06 — Budget

**Statut :** `CONSTITUTION` · v1 · Septembre 2026
**Source :** Master Brief §18

Le budget est suivi comme une vraie entreprise. Trois scénarios, recalculés
régulièrement. **Ne jamais engager une dépense importante sans justification.**

## Scénario 1 — Prototype minimal (démontrer le concept)

Budget cible : **0 – 500 €/mois**

Privilégier : open source · crédits gratuits · exécution locale · free tiers ·
petit serveur.

## Scénario 2 — MVP (produit réellement utilisable)

Budget cible : **500 – 3 000 €/mois**

Inclure : infrastructure · IA · stockage · bases de données · monitoring ·
domaine · services externes.

## Scénario 3 — Plateforme avancée

Budget cible : **3 000 – 20 000+ €/mois**

Inclure : plusieurs utilisateurs · simulation · agents · 3D · données massives.

## Position actuelle (audit v1)

Le projet est aujourd'hui en **scénario 1**, et largement sous la barre basse :

- tous les dépôts sont gratuits (hébergement GitHub public) ;
- la visualisation 3D (Watchtower) fonctionne **sans clé** (mode gratuit) ;
- la seule dépense variable réelle est l'**API Gemini** utilisée côté serveur
  dans proto-cognitorium (extraction de CV / distiller IA), plafonnable ;
- les clés payantes (Google Maps, Cesium ion, OpenAI) sont optionnelles et
  fournies par l'utilisateur.

→ À confirmer par un relevé de coûts réels (voir audits/costs, à produire).
